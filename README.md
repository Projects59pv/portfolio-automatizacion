# Portfolio de automatización · Diana Pereira

Dos trabajos verificables. Se pueden probar en la página publicada y revisar el código aquí.

| Trabajo | Demo | Qué demuestra |
|---|---|---|
| Calculadora de horas del despacho | [`calculadora-horas/`](calculadora-horas/) | Herramienta web de captación: el despacho calcula con sus propios datos el tiempo y el dinero que le cuesta pedir documentos. HTML, CSS y JavaScript sin dependencias, accesible, en modo claro y oscuro, sin guardar ni enviar datos. |
| Seguimiento de compradores para un agente inmobiliario | [`seguimiento-compradores/`](seguimiento-compradores/) | Mini aplicación de gestión que sustituye una hoja compartida: alta y edición de contactos, estados, próxima acción con fecha, avisos de atrasados y de contactos fríos, mensajes de seguimiento según el estado (con enlace a WhatsApp) y exportación a CSV. HTML, CSS y JavaScript sin dependencias; los datos se guardan solo en el navegador. |
